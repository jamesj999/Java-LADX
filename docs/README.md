# Documentation index

Users supply their own ROM. Never commit ROMs or extracted original assets.

## Start here

New contributors: read AGENTS.md, then BUILDING.md, ARCHITECTURE.md and TESTING.md.
Consult the rendering, ROM and audio references for the subsystem you change;
check reconstruction status before making fidelity claims.

record narrow observations, not current implementation requirements.
