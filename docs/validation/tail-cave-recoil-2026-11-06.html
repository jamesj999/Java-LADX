Recoil and power-up regression

345 normal-input checkpoints complete from a fresh game in Java and the original ROM in headless PyBoy. Both finish with the Compass and two Small Keys. The Java run also collects and dismisses a Piece of Power, then resumes sword combat.

Recoil preserves speed for its countdown, stops at walls and cannot trigger an ordinary room transition while active. Power-ups use a finite pickup presentation, dialogue and release instead of becoming permanently carried objects.

This is progression evidence, not combat or visual parity: final health is Java 4/24, ROM 24/24. Enemy phases, drops and explicit combat input variants differ. Loading speed is not a parity requirement. Full-frame RGB555 comparisons use no masks or alignment; 8 of 345 frames match exactly.
