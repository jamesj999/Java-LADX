Chest item sprite correction

The chest table is a list of single 8×16 sprites. Decoding it as pairs doubled the item index and read unrelated ROM bytes. The corrected Small Key uses tile $CA and attributes $17 from $07:7B57.

Exact key region: x=132..139, y=20..35. RGB555 differences: 97 before → 0 after. The wider 16×24 chest region also matches exactly (178 → 0). Full frames are included below; the remaining 198 differing pixels are outside that chest region. No full-screen parity claim.
